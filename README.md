# ThodMixer

**ThodMixer** — это мощный и удобный аудиомикшер с поддержкой MIDI-контроллеров, предназначенный для стримеров, подкастеров, музыкантов и всех, кто хочет получить профессиональный звук без сложных программ.

### Основные возможности

- До 20+ дорожек (Input Strips) с индивидуальной громкостью, mute/solo, гейтом, компрессором и нормализацией  
- Несколько выходных шин (Buses) с маршрутизацией и общей громкостью  
- Полная поддержка MIDI-устройств (CC, Note On/Off, Pitch Bend)  
- Назначение любых MIDI-контролов на громкость, mute, solo, маршруты (learning mode)  
- LED-обратная связь на контроллере (поддержка Launchpad, X-Touch Mini, APC и др.)  
- Управление медиа-кнопками (Play/Pause, Next/Prev Track) через MIDI  
- Автозапуск с Windows  
- Экспорт / импорт настроек (JSON)  
- Блокировка интерфейса одним кликом  
- Минималистичный и красивый интерфейс на WPF

### Как использовать

1. Скачай последнюю версию из [Releases](https://github.com/ThodProd/ThodMixer/releases)  
2. Распакуй архив  
3. Запусти `ThodMixer.exe`  
4. Подключи MIDI-контроллер (если есть)  
5. Выбери входные/выходные устройства в интерфейсе  
6. Настрой маршруты и MIDI-маппинг
