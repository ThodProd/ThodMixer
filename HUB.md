# ThodHUB

Пакет `hub/manifest.json` запускает существующий WPF-микшер отдельным окном.
ThodHUB управляет скачиванием, версиями, обновлением, удалением и ярлыком.
Исполняемые файлы содержат .NET runtime и не требуют SDK у пользователя.

Если задана переменная `THODHUB_DATA_DIR`, конфигурация сохраняется в ней.
При самостоятельном запуске без переменной сохраняется прежний `config.json`.
Настройки аудиоустройств и MIDI не включаются в репозиторий или пакет.

Автозапуск отключён при запуске через ThodHUB, чтобы версия не оставляла системные записи после удаления. Самостоятельный запуск сохраняет прежнее поведение.
